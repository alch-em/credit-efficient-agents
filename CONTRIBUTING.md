# Contributing

Thanks for improving Credit-Efficient Agents.

- Open an issue describing the problem, intended behavior, and affected platform.
- Keep contributions small and test installation/removal behavior on the intended OS.
- Preserve existing instructions, create backups before edits, and keep dry-run side-effect-free.
- Do not add telemetry, secrets collection, automatic deployment, or destructive default behaviors.
- Document known limitations. Never promise a specific usage reduction without reproducible evidence.
- Use clear language and keep the global rules short.

By contributing you agree your contributions are licensed under MIT.
